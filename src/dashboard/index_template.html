Read the numbers with their caveats. Sprint, release version, module, feature, component, status, resolution, priority and closure dates are derived fields — the source Kaggle dataset carries no workflow state and no delivery taxonomy. See the project README under “Derived Fields” and “Known Data Limitations” before treating any aging, velocity or team-performance figure as real-world behaviour.

The priority model on the Models & triage view was trained on a 20,000-row sample of this same dataset, so use the Held-out test split when reading agreement — the training rows are memorised, and priority is itself a derived field, so the model recovers a documented scoring rule rather than real triage.
